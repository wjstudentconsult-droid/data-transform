2 เลือกคำสั่ง Transform

💡 ถ้ามีข้อคำถามเชิงลบ ให้เพิ่มคำสั่ง Reverse Code ก่อน แล้วเลือกตัวแปรที่กลับค่าแล้ว (เช่น q3_r) มาหาค่าเฉลี่ย — ตัวแปรจากคำสั่งก่อนหน้าจะปรากฏในรายการพร้อมป้าย ใหม่
ค่าจะถูกเรียงจากน้อยไปมาก เช่น 1,2,3 → กลุ่มแรกคือ 1
ตัวอย่าง: ตัวแปร edu ค่า 2 → edu_2 (1 = ใช่, 0 = ไม่ใช่, ค่าว่างคงเป็นค่าว่าง)
ต่ำสุด สูงสุด
5→1, 4→2, 3→3, 2→4, 1→5 (สูตร: ค่าใหม่ = ต่ำสุด + สูงสุด − ค่าเดิม)
ค่าที่อยู่นอกช่วงหรือไม่ใช่ตัวเลข จะกลายเป็นค่าว่าง (System Missing)
